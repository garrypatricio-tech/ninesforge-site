# ninesforge.com

Static landing page for NinesForge. Served by Render as a static site from the repository root.

- `index.html`: the page (inline CSS and JS; fonts from Google Fonts)
- `favicon.svg`, `apple-touch-icon.png`, `ninesforge-icon-512.png`: icons and share image

Early-access form: set `data-endpoint` on `<form id="accessForm">` to a form service URL (for example Formspree) to collect sign-ups.
